MyDSH 架构讲解系列

本系列面向有 Kotlin / Java / Dart 背景的读者，逐文件讲解 MyDSH（DeepSeek Harness fork）的核心源码。每篇以仓库权威文档为纲、以源码为据，每个新概念配你熟悉技术栈的类比（🐹 标记）。

篇目

第 01 篇
整体架构与核心概念
分层结构、Cordis 微内核三概念（ctx / 可逆 effect / typed events）、profile→bundle→patch 组合机制、turn/step 生命周期总览、Desktop 启动链路、我们的定制在架构中的位置。
第 02 篇 · core/scope + core/session
作用域原语与事件溯源日志
scope（471 行）：注册向下继承、事件向上冒泡、空插件当所有权锚点。session（3490 行）：SessionEventMap 事件表逐个讲、Session/SessionStore 两阶段发布、surface 表面折算（日志 ≠ 模型历史）、fork/repair/工具史。9 个文件逐一覆盖。
第 03 篇 · core/system-prompt + core/tools
提示组装与工具管线
system-prompt（700 行）：分节/上下文/变量/工具四类注册、中央顺序表、严格插值。tools（3797 行）：三层隔离注册表（shadow/相交限制/单调守卫）、ResolvedToolSet 步骤准入、prepare→dispatch→complete 三段式执行管线、信号熔断、审批 ask 接缝、batch 调度器、schema DSL。10 个文件逐一覆盖。
第 04 篇 · core/agent + core/agent-loop
注册表与驱动器
AgentFactory 接缝、AsyncLocalStorage 发起者归因、initializeAgent 创建事务（yield 定序 teardown）、resume 现场崩溃修复、ReactLoopAgent 状态机（turn/step 主循环逐段拆解）、持久化收件箱、assistant 流三路输出。14 个文件覆盖。
第 05 篇 · llm/llm
适配器注册表与流式词汇
LlmAdapter 抽象（唯一必须实现 stream）、三张注册表（adapters/directory/discoveries）、llm/stream 瀑布、prepareCall 的"绑定一代"语义、ContentBlock 词汇、BlockAssembler 单一组装算法、无损流记录。12 个文件覆盖。附五包系列回顾。
第 06 篇 · 运行时技术栈
Node.js / Electron / pnpm 扫盲
代码之外的运行时知识：Node=V8 出沙箱（对齐 JVM 逐层对照）、libuv 六阶段事件循环、N-API=Node 的 JNI、V8 分层 JIT 与性能真相（IO 密集几乎无差）、Electron 双/三进程模型、contextBridge 安全边界的历史教训、pnpm 的全局 store 与 workspace。附 JVM/Android/Gradle 对照总表。

阅读顺序建议

  1. 先读 01 建立全局图景（约 20 分钟）
  2. 02 → 05 按依赖顺序逐包深入；每篇开头标了覆盖的包与行数
  3. 对照源码阅读体验最佳：packages/core/<pkg>/src/ 下按文档顺序打开文件
